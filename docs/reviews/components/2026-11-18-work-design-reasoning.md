## Scope Delta

- CGG raises only Work Design admission from 8,000 to 32,000 budget tokens.
  Existing input-byte, redaction, source, receipt and complete-editable-context
  guards remain. Other roles retain their budgets. Larger per-field maxima do
  not promise that every maximum-sized field combination fits the aggregate.
- OOS/Console permit 64,000 context characters and 128,000 selected-scope
  characters for these two roles. Identical legacy data can refer to the exact
  admitted scoped field; nonidentical data is retained. No source is silently
  shortened. Only supplied views are known; indexes do not load their contents.
- OOS role instructions distinguish architecture from task decomposition and
  use renderer-owned detail visibility, CSS-pixel sizes and sampled viewport
  facts. The work guide preserves substantive architecture, identities and
  unrelated content. It creates no component count, story count or keyword gate.
- Work Design provider allowance is 600 seconds, enclosed by OOS 630-second,
  Console server 690-second and browser 720-second deadlines. Native bounded
  JSON transport avoids an unrelated fetch header cutoff. Other advice limits,
  reads and canonical Apply retain their existing operation scope.
- Stop, timeout, close and reload retain the original unconfirmed turn and
  draft. Cancel prevents the same button click from becoming a form submission
  when Run returns. A newer manual context rejects a stale proposal. Waiting is
  not represented as verified provider cancellation or fabricated progress.
- Busy and oversized pre-submission refusals are distinct from offline and
  unknown completion. The local model keeps its 4096-token context; a
  conservative preflight refuses clearly oversized input before provider access.
  This is not a tokenizer-exact capacity guarantee or a RAM increase. Capacity
  refusal does not overwrite successful health evidence. Unconfirmed completion
  still stops the existing routing journal from invoking another provider.
  The publication check also proves capacity refusal is terminal: it cannot
  masquerade as unavailable and produce a fallback chain the existing closed
  OOS/Console success-evidence contract rejects. The corrected routing case
  fails before the exception-class repair and then proves one attempt and no
  fallback, without widening consumer allowlists or fallback policy.

native form field, canonical approval or source/release executor is changed.
