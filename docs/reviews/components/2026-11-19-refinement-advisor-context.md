## Scope Delta

- OOS reuses current Catalog choices for PI, Iteration, repository, team,
  assignee/responsible and applicable existing classifications. Native select
  permissions narrow choices. String backend storage does not grant arbitrary
  identifier creation. Derived backlog/retired roadmap versions are not PIs.
  Missing authority blocks governed fields without fabricating a successful read.
- Advice validates a nonempty canonical field subset and its actual source
  values, rather than requiring the entire grouped metadata scope. Mixed values
  remain item-specific; unselected branches and other projects are excluded.
- Bounded typed related drafts belong only to editable fields on selected items
  and ancestors. They remain unaccepted data, distinct from owner source values.
  Canonical planning snapshots retain populated read-only counterparts. Applicable
  field constraints and planning compatibility rules come from the existing owner.
- CGG admits the complete enriched wrapper with closed shapes, unique bindings,
  source/receipt checks, complete redaction/budgeting and replay-sensitive digests.
  Drafts require the matching owner wrapper. Old caller shapes remain compatible.
- Model proposals and accepted Apply values undergo deterministic choice,
  number/date/reference and planning-pair checks. Invalid planning advice returns
  clarification without inserting a value. Native reference existence/type/family
  and final canonical write authority remain with the existing backend.
- Console shows managed values as owner-supplied selectors, filters Iteration
  choices by effective PI and supplied rules, preserves review-needed AI drafts,
  and invalidates stale advice when related drafts change. Narrative and business
  responsibility fields remain prose, not account grants.

Additional bounded repairs preserve per-record choice permissions rather than
restricting every item by the whole-group intersection. Selected-set advice and
per-item Apply independently validate those exact options. Native Integer/Float
constraints survive as numeric typing through admitted context; both preflight
and the native integer writer reject truncation-prone input before effects.

Run/completion display binds the original Work Design handoff; retained runs are
not acknowledgements of a different reviewed request. Newly projected pending
runs include source handoff identity, and legacy completed receipts retain their
original binding. Canonical accepted-payload values are explicitly unavailable
when only the original digest is exposed, rather than fabricated from fresh data.
