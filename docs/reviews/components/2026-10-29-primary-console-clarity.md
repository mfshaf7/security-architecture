## Review Areas

### Identity, private data and read scope

Existing server-only caller bindings, source validation and local Console
identity boundaries remain unchanged. Browser input selects only `oos` or
`wgcf` plus a bounded opaque cursor. Unknown/repeated query fields, malformed
selectors and oversized cursors fail closed. It cannot supply an endpoint,
credential, file path or executable action. Both owner APIs already authorize
history continuation for the existing reader role; no owner scan cap is raised.

Exact owner event facts are preserved beneath the display projection. React
renders them as text, not HTML or executable links. Export contains the loaded
projection, active filters and coverage, not credentials or raw owner transport.
New copies cannot become canonical approvals, receipts or work completion.

### Runtime and AI interaction

Native modal containment prevents background pointer/focus interaction while
preserving the existing independent Agent controller, session and in-flight
request boundary. Closing presentation is not cancellation or a new invocation.
The existing workspace portal and nested review boundary remain independently
validated. Readability changes do not create automatic model requests or loosen
CGG admission. Browser presence counts panels, not backend generation jobs.

Visible-page activity polling is non-overlapping, abortable and bounded. An
uncertain continuation cannot replace retained events, repeat the same cursor
indefinitely, or accept conflicting reused owner identities as new facts.
Source availability, historical event time and current workspace work status
remain distinct. This is local dev-integration acceptance, not a remote/team,
stage, production or whole-product release qualification.
